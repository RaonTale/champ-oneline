챔피언스 한 줄 계산기

포켓몬 챔피언스 · 한 줄 입력 · 데미지 / 결정력 / 내구력

예시
입력법 도움말

포켓몬 이름만 필수. 나머지(능력 포인트·성격·도구·특성·날씨·필드·랭크업)는 띄어쓰기로 구분해 한 줄에 적습니다.

  • 모드 자동 판별
    • 데미지 — 공격정보 기술 vs 방어정보  (vs · -> · => 가능)
    • 결정력 — 공격정보 기술  (vs 없이 기술만)
    • 내구력 — vs 방어정보  (맨 앞에 vs)
  • 능력 포인트 — 챔피언스는 노력치 대신 0~32. a32(공격 32), c32(특공), h32 b32 처럼. 한글로 공32 방32 도 가능. 성격 보정은 뒤에 +/- → a32+. 여러 능력치를 묶어 hd32+(= h32 d32+), hb32 처럼도 됩니다 (성격 보정은 체력이 아닌 능력치에 적용). 한/영 전환 없이 한글 자판 그대로 ㅁ32+(=a), ㅗ(h) ㅠ(b) ㅊ(c) ㅇ(d) ㄴ(s) 도 인식합니다
  • 랭크업 — +2, -1 (숫자 1~6)
  • 메가진화 — 리자몽Y / 메가입치트 처럼 폼 이름을 직접, 또는 도구로 가디안 가디안나이트
  • 날씨/필드 — 입력창 위 날씨·벽 토글로 켜거나(같은 날씨 다시 누르면 꺼짐), 글로 맑음 비 모래 눈 · 일렉트릭필드 사이코필드 등. 글에 날씨/벽을 적으면 해당 토글이 자동으로 켜져(🔒) 고정됩니다. 가뭄 같은 특성명을 쓰면 날씨도 함께 적용
  • 도구·상태이상 — 생명의구슬 진화의휘석… · 화상 맹독 등
  • 특성 — 안 적으면 사용률 1위 특성이 자동 적용됩니다 (예: 마릴리 → 천하장사). 다른 특성을 쓰려면 이름을 함께 적으세요 (예: 두꺼운지방 마릴리, 초식 마릴리)
  • 기타 — 3타(연타, 기술별 최대까지 · 찍찍베기는 10타), 급소, 분산(더블 광역기), 리플렉터/빛의장막, 50%(잔여 체력)
